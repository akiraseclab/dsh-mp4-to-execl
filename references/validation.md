# 质量验收

- 只能根据实际视频生成脚本；原声未转写时明确声明。
- 逐镜对齐画面、字幕、台词、道具、起止时间与截图；完整覆盖视频时间轴。
- 对比原模板与输出：标题、表头、镜号、公式、合并区域、样式、图位和未授权格。
- 校验文件存在、ZIP 完整性、输出不是模板原件。
- 必须如实记录不能辨认的内容、实际用到的视觉/音频工具、是否进行了 Excel 渲染预览。

原始 Skill 安装包曾通过本地视频抽帧、音轨提取和默认/用户模板定点更新测试。GitHub 分发版本增加了默认模板生成脚本，需在实际环境重新验证；未完成真实 DSH 客户端、平台链接下载、ASR 或 Excel GUI 的端到端测试。
